## Historical baseline

The root-level data files retain the earlier 122-assignment baseline. The current release has 123 assignments after the AutoDroid L2-R correction; both have 55 coded sources and 75 claims. Use the current release files for the manuscript.

The original [evidence-20260908 tag](https://github.com/kqcoxn/gui-memory-evidence/tree/evidence-20260908) and its file hashes remain unchanged. Its complete snapshot is also preserved in the current release's `baseline/` directory. Historical sample forms remain blank; their state is documented in the current release and does not represent outstanding sampling work.
