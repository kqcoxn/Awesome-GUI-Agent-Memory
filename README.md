# GUI-agent memory evidence

Companion data for **Memory for GUI Agents: A Framework Survey of Lifecycles and State Layers**.

## Evidence

The [evidence package](releases/evidence-20260913-r4.18/README.md) contains 75 claims from 55 coded sources, 24 mechanism comparisons, and the supporting retrieval and evaluation records. Publication coverage extends through 10 September 2026.

- [Collection and coding methods](releases/evidence-20260913-r4.18/current/evidence_methods.md)
- [Claims and source passages](releases/evidence-20260913-r4.18/current/claims.json)
- [Lifecycle–state matrix](releases/evidence-20260913-r4.18/current/capability_matrix.csv)
- [Source profile](releases/evidence-20260913-r4.18/current/corpus_profile.csv)
- [Mechanism comparisons](releases/evidence-20260913-r4.18/current/mechanism_comparisons.json)
- [Channel counts and source acquisition](releases/evidence-20260913-r4.18/current/acquisition_records.json)
- [Queries and retrieval records](releases/evidence-20260913-r4.18/baseline/search/)

Run `python validate.py` from the package directory to check hashes, counts and record links. Earlier versions remain available through [version tags](https://github.com/kqcoxn/gui-memory-evidence/tags).

## Source access

Research annotations and attributed excerpts link to the original publications. Source material retains its applicable rights. Full texts are available through the recorded source URLs.
